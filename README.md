# EchoAlertAppCrossPlatform

EchoAlert Cross-Platform Application.

## Getting Started

This repository contains the source code for the EchoAlert Cross-Platform App.

### Prerequisites

- Flutter SDK / Android SDK / Node.js (depending on project stack)

### Setup & Run

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Install dependencies.
3. Run the application.
